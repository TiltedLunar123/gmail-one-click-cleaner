# Gmail One-Click Cleaner terms of use

**Effective 2026-07-28.**

The extension is free, and its source code is public on GitHub under the MIT license. Pro is
an optional one-time purchase that unlocks extra features with a license key shown on the
activation page right after checkout.

- **Pro costs $9.99 once**, with no subscription and no renewal. If you are running an older
  version, its Get Pro button may still point at an earlier $5 checkout link, which is
  deliberately kept alive so those builds keep working. Either link buys the same lifetime
  Pro, including features added later.

- **Losing your key is recoverable, free.** If Pro is active in any browser you can copy the
  key straight out of Options. Otherwise revisit the link Stripe sent you to after checkout,
  or re-issue it from the email address you paid with. Because that address is all recovery
  needs, treat it as your proof of purchase: anyone with access to it can obtain a working
  key. Keys are not tied to a device or an account, never expire, and cannot be revoked once
  issued. A re-issued key is a new token for the same purchase, so keys you already have keep
  working.

- A Pro key is for your own use. Don't share, resell, or publish license keys.

- Payments are processed by Stripe. If a purchase goes wrong or Pro doesn't work for you,
  email us and we'll make it right, including a refund when that's the fair outcome. Because
  keys are verified offline and cannot be revoked, a refund relies on you no longer using Pro.

- **You choose what gets cleaned, and you're responsible for those choices.** Deletions go to
  Gmail's Trash, which Gmail keeps for about 30 days; after Gmail empties it, that mail is
  gone for good. Use dry-run or review mode when unsure.

- **One-click restore has limits worth knowing.** A run can be put back only when its label
  was applied successfully, and the recovery log keeps only your last 20 runs. If labelling
  fails the cleanup still proceeds and that run cannot be restored from the log; deleted mail
  is then recoverable only by hand from Trash, within Gmail's window. Archived mail has no
  deadline, since it is never deleted.

- **Schedules and Auto-Pilot act on their own.** If you turn them on, the extension will clean
  on a recurring basis while you are not watching, without asking each time. Auto-Pilot only
  ever archives, never deletes, and its first sweep is a preview that touches nothing until
  you approve it. You can switch either off at any time. A copy of the extension that was not
  installed from an official store is blocked from running these unattended, on purpose.

- The extension works by driving Gmail's own interface, so a Gmail redesign can break features
  until a fix ships. It's provided as is, without warranties; to the fullest extent the law
  allows, our total liability is capped at what you paid for Pro.
